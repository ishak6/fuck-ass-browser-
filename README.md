# Custom Browser

Native Android browser project built with Kotlin, Jetpack Compose and first-party modular browser components.

**Engine status:** The first-party rendering engine is not implemented yet. The app currently displays an honest native initialization screen. It does not use WebView, GeckoView, Chromium or another browser engine.

See [ARCHITECTURE.md](ARCHITECTURE.md), [FEATURES.md](FEATURES.md), [ROADMAP.md](ROADMAP.md) and [PROGRESS.md](PROGRESS.md).
